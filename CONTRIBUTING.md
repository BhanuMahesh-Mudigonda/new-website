# Contributing to PB Photography

Thanks for your interest in contributing to PB Photography's website. We welcome improvements, bug fixes, and content updates.

How to contribute

1. Fork the repository (if you don't have push access).
2. Create a feature branch: `git checkout -b fix/your-change`.
3. Make changes and test locally: `python3 -m http.server 8000` and view in the browser.
4. Commit your work with a clear message.
5. Push to your fork and open a Pull Request describing the change.

Code style

- HTML/CSS/JS: keep code readable and consistent with the existing style.
- Images: commit optimized images (WebP or compressed JPEG/PNG) and keep sizes reasonable.

Reporting issues

- Open an issue describing the bug or feature with steps to reproduce and screenshots when appropriate.

Thanks — we look forward to your contributions!
